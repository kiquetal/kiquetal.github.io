Configuración y Despliegue
de NATS en Fly.io

✦ ❦ ✦
Paso 1: Crear Dockerfile
FROM nats:2.10.25-alpine
# Exponer puertos de cliente, gestión y enrutamiento
EXPOSE 4222 8222 6222
# El entrypoint por defecto ya es "nats-server"
CMD ["-js", "-sd", "/data", "-m", "8222"]
✦
Paso 2: Configurar fly.toml
app = "nats-server"
primary_region = "gru"
[[services]]
internal_port = 4222
protocol = "tcp"
✦
Paso 3: Desplegar
$ fly deploy
$ fly scale count 1
✦
Paso 4: Configurar Secretos
$ fly secrets set NATS_USER=admin
$ fly secrets set NATS_PASS=secret
