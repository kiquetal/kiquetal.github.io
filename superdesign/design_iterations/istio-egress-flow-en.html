Istio Egress Gateway

Routing External Traffic to cnn.com
✦ ❦ ✦
ServiceEntry
Registers external service in Istio's service registry
Virtual Service
Routes traffic through egress gateway
Destination Rule
Applies TLS and connection policies
✦
1
ServiceEntry: Register External Service
Tell Istio about cnn.com so it knows this external service exists
apiVersion: networking.istio.io/v1beta1 kind: ServiceEntry metadata: name: cnn-external spec: hosts: - edition.cnn.com ports: - number: 443 name: https protocol: HTTPS location: MESH_EXTERNAL resolution: DNS
↓
2
Gateway: Define Egress Gateway
Configure the egress gateway to allow HTTPS traffic out
apiVersion: networking.istio.io/v1beta1 kind: Gateway metadata: name: istio-egressgateway spec: selector: istio: egressgateway servers: - port: number: 443 name: https protocol: HTTPS hosts: - edition.cnn.com tls: mode: PASSTHROUGH
↓
3
Virtual Service: Route to Gateway
Direct traffic from pods → egress gateway → external service
apiVersion: networking.istio.io/v1beta1 kind: VirtualService metadata: name: direct-cnn-through-egress spec: hosts: - edition.cnn.com gateways: - mesh - istio-egressgateway http: - match: - gateways: - mesh port: 443 route: - destination: host: istio-egressgateway.istio-system.svc.cluster.local port: number: 443 - match: - gateways: - istio-egressgateway port: 443 route: - destination: host: edition.cnn.com port: number: 443
↓
4
Destination Rule: Apply Policies
Configure TLS settings and connection pool policies
apiVersion: networking.istio.io/v1beta1 kind: DestinationRule metadata: name: cnn-destination spec: host: edition.cnn.com trafficPolicy: tls: mode: SIMPLE
✦ ❦ ✦
Execution Order: ServiceEntry → Gateway → VirtualService → DestinationRule
