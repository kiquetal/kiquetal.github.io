AES-GCM-256 Protocol

Standardized cryptographic security flow for web applications

✦ ❦ ✦

Initialization Vector (IV)

  • 96-bit (12 bytes) recommended size to prevent collision
  • Must be unique for each separate encryption operation
  • Generated using cryptographically secure random numbers

Key Derivation (PBKDF2)

  • Converts user passwords into strong encryption keys
  • Utilizes secure salt and 100,000+ hashing iterations
Cryptographic Sequence
User Password → PBKDF2 → 256-bit Key → AES-GCM (+ IV) → Authenticated Ciphertext
