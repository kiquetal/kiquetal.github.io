Cifrado AES-GCM-256

Flujo de seguridad criptográfica estándar para aplicaciones web

✦ ❦ ✦

Vector de Inicialización (IV)

  • Tamaño recomendado de 96 bits (12 bytes) para evitar colisiones
  • Debe ser único para cada operación de cifrado independiente
  • Generado mediante números aleatorios criptográficamente seguros

Derivación de Clave (PBKDF2)

  • Convierte contraseñas de usuario en claves de cifrado robustas
  • Utiliza una sal segura y más de 100,000 iteraciones de hashing
Secuencia Criptográfica
Contraseña → PBKDF2 → Clave de 256-bit → AES-GCM (+ IV) → Texto Cifrado Autenticado
