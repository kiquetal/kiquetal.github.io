The Either Sealed Interface

  • Defined as a 'sealed interface' permitting only nested 'Right' and 'Left' records.
  • Forces exhaustive compile-time checking in Java 'switch' expressions without default branches.
  • Eliminates raw exception throws, modeling errors as standard return values instead.

Left Record (The Failure Path)

  • Holds the error payload of generic type E (e.g. ValidationError, DatabaseError).
  • Its map() and flatMap() methods immediately bypass operations, returning 'this' casted.
  • Acts as a failure track bypass: once a step fails, all remaining steps are skipped.

Right Record (The Success Path)

  • Holds the successful computation value of generic type T (e.g. User, Account).
  • Its map() method transforms the value into a new Right instance using the mapper function.
  • Its flatMap() method chains another operation that returns an Either, potentially switching tracks on failure.
